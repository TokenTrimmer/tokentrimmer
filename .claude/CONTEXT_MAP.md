# Context map

**Purpose**: the path of least resistance to whatever context a task needs. First-stop lookup before any subagent does a fresh `rg`/`Glob`.

**How to use**:
1. Find your topic in the **Domains** table.
2. Open the files listed (with line ranges where stable).
3. Read the **Cross-cutting concerns** if your task touches more than one domain.
4. If your topic isn't here, run `./scripts/context-for.sh <topic>` for an automated lookup, then **add what you learn to this file** so the next task is cheaper.

This file is the human-curated counterpart to `.claude/INDEX.md` (auto-generated by `scripts/context-map.sh`).

## Cross-cutting concerns

### Cost discipline & dogfooding

- **Model routing for subagents**: `.claude/MODEL_ROUTING.md`
- **Cost ledger**: `.claude/cost-ledger.jsonl` (per session)
- **Cost circuit breaker**: `.claude/hooks/cost-cap-check.sh` writes `.claude/PAUSED`
- **Per-edit guard rules** (dogfood our own Inspect rules): `.claude/hooks/pre-edit-guard.sh`
- **Anthropic SDK `cache_control`**: auto-injection logic in `crates/providers/anthropic/src/translate.rs` (TBD Week 3)

### Session lifecycle

- **Active handoff**: `.claude/HANDOFF.md` (read by session-start, written by `make session-end`)
- **State pointer**: `.claude/STATE.md`
- **Audit log**: `.claude/AUDIT.log` (one line per session, gitignored)
- **Backlog**: `.claude/BACKLOG.md` (CLI: `make backlog{,-take,-sync}`)
- **Hooks**: `.claude/settings.json` references `.claude/hooks/*.sh`

### Autonomous loop control

- **Full protocol**: `.claude/AUTOPILOT_PROMPT.md` (versioned in repo)
- **Start the chain**: ask the assistant "start the autopilot" → first `ScheduleWakeup` fires in 60s; each iteration schedules its successor
- **Stop the chain**: ask the assistant "stop the autopilot" → assistant cancels pending wakeup; chain ends
- **Pause** (next iteration self-aborts, manual resume): `make loop-pause` → writes `.claude/PAUSED`; `make loop-resume` to clear
- **One-shot stop**: `touch .claude/STOP-CHAIN` (next iter aborts AND deletes file)
- **Check status**: `make loop-status`
- **Manual single iteration** (no chain): `make loop`
- **Hard end**: close Claude Code — all wakeups die immediately, chain ends naturally
- **Iteration cost cap**: enforced inline ($1/iteration); `cost-cap-check.sh` also writes `.claude/PAUSED` if daily/weekly caps exceeded

### Decisions (the "why it is this way")

- See `.claude/DECISIONS.md` for the ADR log.
- Always cross-reference a decision when changing something the decision was about — that's how you avoid re-litigating closed questions.

### Plans (in-repo, version-controlled)

- `.claude/plans/` — master plan + follow-up plans. Each ends with a "Backlog items" section that becomes BACKLOG.md entries.
- `.claude/plans/00-master-buildout-plan.md` — 26-week solo-founder roadmap (Week 0 → beta).
- Pattern: when a plan is finalized via `/plan`, copy it here as `NN-<name>.md` and extract its checklist into `.claude/BACKLOG.md`.
- `make plans` to list.

### Session history (auditable)

- `.claude/HANDOFF.md` — ACTIVE handoff (overwritten each session-end)
- `.claude/sessions/` — ARCHIVED handoffs (one file per session, never overwritten)
- `.claude/SESSIONS.md` — index of archives, newest at bottom
- `.claude/AUDIT.log` — append-only one-line-per-session log
- `make sessions` to browse

## Anti-context (looks relevant but isn't)

- `docs/tokentrimmer-architecture-spec-v1.md` — 1300+ lines. **Don't load** it for routine work. Use the four focused spec docs (`01-inspect-rule-catalog`, `02-provider-adapter-guide`, `03-plan-replay-design`, `04-gateway-api-reference`) instead. Skim the architecture spec only for system-wide questions.
- `crates/providers/<name>/src/lib.rs` (most are 2-line stubs) — don't waste a Read; check the Cargo.toml for what's actually there.
- `Cargo.lock` — informational only; never edit.
- `.claude/AUDIT.log`, `.claude/cost-ledger.jsonl`, `.claude/reflections.jsonl` — append-only; read only for measurement, never as task context.

## Updating this map

This file becomes wrong as the code changes. To prevent rot:

1. When you add a non-trivial module or doc, add it here too (one line in the right table).
2. When `scripts/context-for.sh <topic>` returns "no map entry" but you found the answer, append a "If you're doing" row.
3. After each weekly review, prune entries pointing to files that no longer exist.
4. `scripts/context-map.sh` regenerates `.claude/INDEX.md` (the structural facts); this file is the *editorial* layer on top.
