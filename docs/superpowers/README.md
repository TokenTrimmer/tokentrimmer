# Historical implementation records

Everything under `plans/`, `specs/`, `workflows/`, and `recipes/` is an archived point-in-time design or execution record retained for provenance only.

Do not execute these documents or treat their checkboxes, snippets, dependency versions, endpoint shapes, rollout instructions, or readiness claims as current work. Current behavior and contracts come from source, migrations, generated CLI help, focused tests, and `PROJECT_REVIEW_2026-08-11.md`; deployment authority comes from the active CI and release gates.

New work must update the owning source and its observable contract. Do not add another plan or readiness catalog unless it closes a current user-facing gate.
